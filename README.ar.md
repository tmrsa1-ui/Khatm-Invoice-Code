# ختم فاتورة — Khatm Invoice

أداة عربية للفحص التقني المحلي للفواتير الإلكترونية السعودية.
تفك رمز QR (TLV/Base64)، وتفحص XML، وتراجع المجاميع، وتقارن الرمز بالمستند.

**ختم فاتورة ليست تابعة لهيئة الزكاة والضريبة والجمارك، ولا تمثل اعتمادًا أو موافقة رسمية.**

`PASS_LOCAL_RULES` ليس «معتمدة». تجزئة الفاتورة وC14N11 تبقى `INCONCLUSIVE`.
XSD وSchematron تبقيان `NOT_CHECKED` حتى يوفّر المستخدم الملفات خارج Git.

لا توليد فواتير، لا توقيع، لا رفع إلى فاتورة.

العقد التجاري مسودة غير موقّعة في `docs/commercial-contract.md`.
